# 报价

本项目注塑报价的编排入口。**完整规范（字段定义、取数规则、Excel 列映射、公式）只有一个权威来源：`报价自动化/内部报价格式.md`。开算前先读它，按它执行。改规则改那里，不要在本 skill 里另写一套。**

配套内部库：材料单价查 `报价自动化/材料价格.md`，机台费率查 `报价自动化/机台费率.md`。
Excel 母版（只读、勿改）：`注塑项目/自动化报价/产品报价内部格式.xlsx`。

## 启动即执行

1. **先弹「需要你提供什么」清单**（每次启动必打印，分三档）：

   > **① 必填**：模具费 —— 不给无法算总价，拿不到就停。
   > **② 最好人工提供（有兜底，给了更准）**：材料单价、机台费率、机台大小/吨位。不给我会分别用 `材料价格.md`、`机台费率.md`、投影面积×系数 兜底，并在来源表里标明是兜底/估值。
   > **③ 其余不用你管**：我从资料文件夹自动挖 / 按规则估算（均可 override）。

   模具费拿不到不往下走；②③ 用户不给则照兜底继续。

2. **确认客户资料文件夹**，没给就问是哪个。

3. **读完文件夹里每一个文件**，读不了的点名说明哪个没读、为什么。

4. **按 `内部报价格式.md` Part 0 逐零件挖字段**（产品尺寸→锁模力选机、模穴数、取数、分摊期总产量、月批量、重量、料头、段取、材料品种牌号、加工时间、机台费率…），价格落到内部库，不凭空造。

5. **产出一个新的「数据来源表」MD**（required，每次必做）：表格列出每个字段的 值(带单位) | 来源(文件/行/sheet，能交叉验证就写双源) | 含义。存到当次项目目录。

6. **复制 Excel 母版一份**（`产品报价_<项目/日期>.xlsx`），把数据填进**副本**算总价。母版保持只读干净。**填副本必须复制模板行（第4行）的完整样式（字体/填充/边框/对齐/数字格式）并用 Translator 按行号平移公式——不能写纯文本、不能丢公式；参数改动（如利润率、分摊基数）要落进对应公式**。详见 `内部报价格式.md` §填副本。

7. **运输/包装用 floor**：默认 simulate 出让实际占比真正 ≥ 8% / 5% 的绝对金额；**≥850T 大件改为运输 10% / 包装 10%（分母 0.784）**；正好命中 OK，绝不能把 4.74% 四舍五入当 5% 蒙。

## 硬规则（详见 `内部报价格式.md`，务必遵守）

- **一个项目归一个项目**：绝不跨项目套用别项目数据/「正确答案」，每次从当前文件夹官方图纸/Part List 重新取数。
- **产量取邮件/口述，不取图纸/BOM**；模具分摊按分摊年限（≠生命周期年限）× 年量算总量；分摊数量取邮件「3年分摊数量」。
- **只报注塑件**（PROCESS=Injection）；压制件（Pressing）、外购/装配件（铆钉/码钉等）不纳入，来源表点名排除。
- **多件共用一副模的分摊**：每件 AK = 模具费 ÷ 共用件数 ÷ 分摊数量。**段取随吨位跳档**要重算。
- **成本占比分母 = 总成本 − 模具费**。
- **家族模 vs 分机**、**外观工艺每件必做**（外观件优质钢+皮纹加晒纹费）。**报废率按可视与否：装车后任何能被看到的件（内饰外观件/可视件）报废率一律 15%（U/AA 列 = 0.15）；常规不可视件维持 1%。此值是用户刻意定的风险余量，非手误。用到 15% 必须在数据来源表注明「为什么 15%（＝判为可视件）」＋「判为外观件的出处（文件/页/字段）」，缺一不可。**
- **重量**：Part List 标注优先；没标才 STP 体积 × 密度（**密度从资料/物性表取，不用模板 1.2**）。**料头 ≥15%**。
- **段取按吨位**：<360t=15kg / 360t=25kg / 850t·1300t=50kg（Excel R 列单位 g，填表 ×1000）。
- **加工时间**默认 160t=30s / 360t=50s，标「需专家评估」。
- **输出带单位、英文加中文释义**（文件名和 mm 除外）；公差必带单位。
- **Excel 默认只读**：母版永远只复制不改；格式转换/导出只读原文件、输出新文件。
- **md 是自己生成的，不是数据来源**：数据一律以官方图纸/Part List/技术协议为准。
