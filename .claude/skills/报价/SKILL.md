## 执行流程

1. **确认询价文件夹**。用户没给就先问是哪个文件夹。

2. **读完文件夹里的每一个文件**，一个都不跳。读不了的（加密/格式不支持）必须明确说明哪个没读、为什么。

3. **先产出 `数据来源表.md`**（早于任何计算）：逐项列出「体积 / 重量 / 颜色 / 材料牌号+供应商」是什么 + 来自哪个文件哪一行/标题栏/sheet。同一数据多源出现要交叉验证并列出所有来源。取数优先级：**文件标注值 > STP 计算 > 经验估值**，估值项显式标「估值/待补」。

4. **按报价决策树逐模块计算**：材料费 → 模具刀具摊销 → 加工费 → 汇总加利润。（决策树文件待重建；重建前用材料价格表 + 机台费率表 + 下方硬规则计算。）

5. **对照报价检查清单逐条自检**后再出结论。（检查清单文件待重建。）

6. **按 `报价自动化/内部报价格式.md` 输出**。

## 硬规则（本项目踩过坑，必须遵守）

- **一个项目归一个项目**：绝不跨项目参考/套用别项目数据或「正确答案」，每次从当前文件夹的官方图纸/Part List 重新取数。
- **产量取邮件/用户口述，不取图纸/BOM**：优先级 用户口述 > 询价邮件 > 图纸/BOM。年产值 = Σ(每个零件号年需求 × 该零件含税单价)，零件号逐个数，不要合并成「套」再除年限。模具费分摊量用邮件标注的「3年分摊数量」。
- **成本占比分母 = 总成本 − 模具费**，不是全部成本。
- **家族模 vs 分机**：材料相同、壁厚接近 → 优先家族模；材料不同或壁厚差 >1mm → 分机。不要默认一件一机。
- **外观工艺每件必做**：判外观件/内饰件、有无皮纹；外观件用优质钢+浇口避可见面+废品率≥1.5~2%，皮纹加晒纹费。不得用裸模价/默认 1% 蒙混。
- **输出带单位、英文加中文释义**（文件名和 mm 除外）；公差必带单位。
- **Excel 默认只读**，除非用户明确说「改 Excel」；格式转换/导出 PDF 只读原文件、输出新文件，不改原始文件。
- **md 是自己生成的，不是数据来源**：数据一律以官方图纸/Part List/技术协议为准。
