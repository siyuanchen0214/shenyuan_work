# 包装模拟 (pack_sim)

暴力仿真：**零件(6种朝向) ─► 纸箱(箱型程序优化) ─► 货车车厢(体积+限重)**，
目标 = **纸箱料费 + 运费** 综合最低，分装(每种件单独装箱) 与 混装(不同件同箱) 都跑并对比。

## 权威文件（都在项目数据目录，不在本 skill 里）

引擎与参数的唯一真身在：`注塑项目/金榕/GEA 顶配 模具计划/包装模拟/`
- **`config.py`** —— ★参数表，就是"慢慢往里填"的地方。每个值都可调；带 `★待确认` 的是占位值。
- **`pack_sim.py`** —— 引擎，逻辑改这里。运行即出结果。
- **报告** —— 每次运行自动写一份带时间戳的 `pack_report_<时间戳>.md`，**默认就落在同一个文件夹里**（历史都留着）。位置由 `config.OUTPUT_DIR` 控制：留空=同目录，也可填子文件夹名或绝对路径。

## 怎么跑

```
cd "注塑项目/金榕/GEA 顶配 模具计划/包装模拟" && python3 pack_sim.py
```
依赖：`py3dbp`(混装用，缺了自动跳过混装)。结果同时打印 + 写成报告文件(位置见 `OUTPUT_DIR`)。

## 参数（全在 config.py，都可调）

| 组 | 参数 | 说明 |
|---|---|---|
| 零件 | `PARTS` | 名称+长宽高(cm，STEP实测已定稿)+单件重量kg(★待填) |
| 车厢 | `TRUCK_INNER_CM` / `TRUCK_PAYLOAD_KG` / `TRUCK_COST_YUAN` / `TRUCK_FILL_EFF` | 内尺寸/限重/每趟运费/装载利用率 |
| 纸箱 | `CARDBOARD_YUAN_PER_M2` / `PART_CLEARANCE_CM` / `CARTON_WALL_CM` / `MAX_CARTON_EDGE_CM` / `MAX_PARTS_PER_CARTON` | 纸板单价/零件缓冲/壁厚/最长边/单箱件数上限 |
| 订单 | `SETS_TO_SHIP` | 发运套数(1套=前+后+左+右) |
| 输出 | `OUTPUT_DIR` | 报告存哪；留空=脚本同目录(默认)，也可填子文件夹或绝对路径 |

**"慢慢填"的工作流**：`config.py` 底部有 `PENDING` 列表，列着还没用真实数据确认的参数。
每跑一次，报告顶部会把 `PENDING` 打成"⚠️占位值"提醒。你确认一个真实值就改对应参数、并从 `PENDING` 删掉它，直到清空——那时结果才算定稿。

## 成本模型

- 纸箱料费 = 箱**外表面积** × `CARDBOARD_YUAN_PER_M2`（∑所有箱）
- 运费 = 需要的**车趟数** × `TRUCK_COST_YUAN`；每趟装箱数 = 车厢可用体积(×利用率) / 箱体积，再与限重取小
- 总成本 = 料费 + 运费；同时报"每套成本"

## 当前局限（可继续往里填/升级）

- **混装用 py3dbp 启发式**(长边卡最长件、横截面码紧凑一捆)，非全局最优，只作对比参考；分装是精确网格暴力。
- 车厢装载用"体积利用率×限重"估算，未做逐箱三维排样；要更精确可在 `pack_sim.py` 里换成对纸箱也做 3D 排样。
- 暂未含：托盘、堆叠承压/"этот面朝上"约束、装卸顺序、体积重(抛货)计费。需要就加进 config + 引擎。

## 数据出处约束

零件尺寸以 STEP 内核实测为准（见记忆 project-gea-dingpeng）；价格/运费/订单量以用户提供的真实值为准，不凭空造。改规则改 `config.py`/`pack_sim.py`，不要在本 SKILL.md 里另写一套数。
