# Part 0 · 字段挖掘规范（报价前必做）

## 工作流

1. 用户丢来**一个客户资料文件夹**（图纸/STP/Part List/BOM/技术协议/模具计划等），dump 进来。
2. **把里面每个文件都读一遍**，读不了的（加密/格式不支持）必须点名说明哪个没读、为什么。
3. **每个零件产出一块来源表**（terminal 输出 + 落盘成新 MD，见下）。
4. **复制一份 Excel 模板再填**：母版 `注塑项目/自动化报价/产品报价内部格式.xlsx` **永远只读、不改**；每次跑 skill **先 make a copy**（如 `产品报价_<项目/日期>.xlsx`，存到当次项目目录），把挖到的数据**填进副本**，由副本算出总价。母版保持干净。**填副本的格式与公式硬要求见下节 §填副本。**

## §填副本（★ 格式 + 公式必须与模板一致，不能写纯文本）

上一次踩过的坑：openpyxl 直接写值 → 数据行变成无格式纯文本、公式列丢公式。**正确做法**：

1. **以母版「模板行」（第 4 行，已带格式+整套公式）为样板**。先把该行每一列的**样式**（字体/填充/边框/对齐/数字格式/保护）和**公式/值**捕获下来。
2. **每个零件行逐列复制模板行样式**（用 `copy.copy` 复制 font/fill/border/alignment，再赋 number_format）——数据行字体、数字格式、单元格高亮必须和模板行**完全一致**。
3. **公式列按行号平移**：用 `openpyxl.formula.translate.Translator(公式, origin="X4").translate_formula("X{r}")`，让 `V/S/AB/AL/AF/AH/AI/AK…` 及年降列（AP/AQ/AS…BB）每行引用自己那行，绝不能还指向第 4 行。
4. **参数改动要落进公式**：如利润率改 15% → `AI` 公式里的 `8%` 改 `15%`；分摊基数 → `AK` 公式 `AJ/{分摊数量}`。
5. 只有**输入列**（B/C/D/F/G/H/J/K/L/N/O/P/R/T/U/W/X/Y/AE/AG/AJ）写值；其余公式列保留公式。**AE/AG 写解出的绝对金额常数**（floor），`AF/AH` 保留占比公式做校验。
6. 存盘后**抽查**几行：确认公式已平移到本行、字体/数字格式 == 模板行。

**① 硬性必填（不给不往下走）**

**② 建议人工提供（有兜底，但人工给更准 —— 作小字提示，不给则走兜底）**

## 取数补充规则（本类项目验证过）

- **模具费分摊（多件共用一副模）**：每件 `AK = 模具费 ÷ 共用件数 ÷ 该件分摊数量`（等价 模具费 ÷（共用件数 × 分摊数量））。例：前 4 件共用 21 万，各件 = 210000/4/229566 = 0.229 元/件。
- **只报注塑件**：`PROCESS=Injection/注塑` 的才报；**压制件（Pressing）、外购/装配件（Assemble，如铆钉/码钉）不纳入注塑报价**，需在来源表点명排除。
- **交叉验证优先双源**：尺寸/重量/材料尽量 **Part List ⇄ 模具制造计划** 两处对照；不一致时取 Part List 标注值并标注差异（如后气坝 Part List 27g ⇄ 模具计划 40g）。
- **分摊数量取邮件「3 年分摊数量」**列，不是生命周期量、不是图纸量。
- **段取随吨位跳档**：吨位一变，段取要重算（如 250T→15kg，升到 360T→25kg）。

## 凑整规则（floor，务必遵守）

运输 8% / 包装 5% 是**下限（floor / 底线）**，不是可逼近的上限。填副本时 **simulate 出让实际占比（AF=AE/AL、AH=AG/AL）真正 ≥ 目标的绝对金额**再填。**恰好等于 8%/5% 可以；但绝不能把 4.74% 这种四舍五入成「5%」来蒙。**

- ❌ 总价 45，包装凑成 2.2 → 2.2/45 = 4.9% < 5%，不行
- ✅ 凑成 2.3 → 2.3/45 = 5.1% ≥ 5%，可以；或直接解出正好 = 5% 的值也行
- 原则：**实际占比宁可略高、绝不略低；正好命中 OK，四舍五入蒙混不行。**
- 注意循环依赖：AE/AG 是 AL 的百分比，而 AL 又含 AE/AG/利润，需迭代或用解析解（见 Part 3）求出正好 ≥ 目标的值。

## 输出格式（★ 每次必产出一个新 MD 文件）

**硬性要求（required）**：**每次跑完 skill，必须生成一个新的 `.md` 文件**（如 `数据来源表_<项目/日期>.md`，存到当次询价文件夹或项目目录），用**表格**把今天定义的字段**全部列一遍**，并逐项标明**数据从哪儿来**。不是只在 terminal 打印——必须落盘成文件。

**每个零件一块，字段纵向列**，每项四要素：

| 字段 | 值（带单位） | 来源 | 含义 |
|---|---|---|---|

- **值**：带单位；英文加中文释义（文件名和 mm 除外）。
- **来源**：具体到文件 / 行 / 标题栏 / sheet。**能交叉验证时，两个数据源都要列出来**（例：重量 → Part List 标 77g ⇄ STP 86cc×0.9=77g，两源吻合）。
- **含义**：这个字段/值代表什么，让你一眼能核。
- 表内字段顺序与 Part 0「每零件字段表」一致，一个都不能少（含运输费、包装费、模具费）。

# Part 2 · 公式固定列（程序直接写公式，不需人工输入）

| 列 | 字段名 | 公式（row 用实际行号替换） |
|---|---|---|
| M | 月批量 | `=ROUND(K{r}/L{r}/12*10000,-2)` |
| S | 使用重量 | `=(N{r}+O{r}*(1-P{r})/H{r})*(1+Q{r})+R{r}/M{r}` |
| U | 不良损耗 | `0.01`（固定值） |
| V | 部品材料费 | `=(S{r}*T{r}/1000)*(1+U{r})` |
| Z | 分钟机台费率 | `=Y{r}/60/0.9` |
| AA | 加工不良损耗 | `=U{r}` |
| AB | 加工费 | `=(Z{r}*X{r}/H{r})*(1+AA{r})` |
| AC | 材料管理费 | `=V{r}*0.03` |
| AD | 加工管理费 | `=AB{r}*0.08` |
| AI | 利润 | `=(V{r}+AB{r}+AC{r}+AD{r}+AE{r}+AG{r})*0.08` |
| AK | 模具分摊 | `=AJ{r}/总分摊量`（总分摊量 = 分摊年限 × 年量，项目级） |
| AL | 总计未税 | `=SUM(V{r}+AB{r}+AC{r}+AD{r}+AE{r}+AG{r}+AI{r}+AK{r})` |

# Part 3 · 运输/包装费的循环引用解法

AE（运输 **8%**）和 AG（包装 5%）如果直接写成 `=AL*8%`，会产生循环引用。
解析解推导（AE+AG = AL×13%，AI = (成本+AE+AG)×8%，回代得分母 = 1 − 13%×1.08 = **0.8596**）：

```
分母 = 0.8596        （= 1 − (8% + 5%) × (1 + 8%)）

AE = ((V + AB + AC + AD) * 1.08 + AK) / 0.8596 * 8%
AG = ((V + AB + AC + AD) * 1.08 + AK) / 0.8596 * 5%
```

> ⚠️ 原始 Excel 模板若仍编码 7% / 分母 0.8704，以本文件今日口径（8% / 0.8596）为准；
> 首次落到真实 Excel 前与专家确认一次。旧值：分母 0.8704 = 1 − (7%+5%)×1.08。
