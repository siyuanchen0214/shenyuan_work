# Part 0 · 字段挖掘规范（报价前必做）

## 工作流

1. 用户丢来**一个客户资料文件夹**（图纸/STP/Part List/BOM/技术协议/模具计划等），dump 进来。
2. **把里面每个文件都读一遍**，读不了的（加密/格式不支持）必须点名说明哪个没读、为什么。
3. **每个零件产出一块来源表**（terminal 输出 + 落盘成新 MD，见下）。
4. **复制一份 Excel 模板再填**：母版 `注塑项目/自动化报价/产品报价内部格式.xlsx` **永远只读、不改**；每次跑 skill **先 make a copy**（如 `产品报价_<项目/日期>.xlsx`，存到当次项目目录），把挖到的数据**填进副本**，由副本算出总价。母版保持干净。

## 必填 / 可选输入

- **模具费 = 必填**。skill 一启动、开算之前**先向用户要**；拿不到不往下走（无法从客户文件推，只能询模具厂/用户给）。→ Excel **AJ**
- **其余所有参数 = 可选 override**（加工时间、段取、料头、利润率、材料单价…）。**不给就用下方默认估算**——问不到专家时用默认兜底。
- **价格一律查内部库**：材料单价 → `材料价格.md`；机台费率 → `机台费率.md`。**不许凭空造价**；材料库里没有的料 → 向供应商询价并附书面报价（POC）。

## 每零件字段表（挖掘顺序 + 规则 + 去向）

| # | 字段 | 取数 / 估算规则 | 典型来源 | → Excel 列 |
|---|---|---|---|---|
| 1 | 产品尺寸 | 读图纸；用于算锁模力（见 #3） | 客户图纸 | 计算用 |
| 2 | 模具穴数 | 读文件 / 模具方案 | 客户文件·模具方案 | G |
| 3 | 机台大小（锁模力） | 锁模力(kgf) = **产品最大一侧投影面积(cm²) × 系数**；**PP=350，PC=450，非 PP 非 PC 一律 450**。→ 换算吨位，**按吨位往高选** | 计算 | W |
| 4 | 模具取数 | 每模这个零件出几件 | 模具方案 | H |
| 5 | 分摊期总产量 | **按「模具分摊年限」× 年量**，不看生命周期年限。年限换算：1 年→×1，3 年→×3，6 个月→×0.5。分摊年限取邮件/口述 | 邮件/口述 | K / L → 总分摊量 |
| 6 | 月批量 | 每月数量；**只给年量就 ÷12 自算** | 客户文件 + 计算 | M（公式） |
| 7 | 重量 | **Part List 已标就直接用**；没标 → STP 读体积 × 密度 自算 | Part List 优先 / STP | N |
| 8 | 料头 | 我方空间，**≥15%**（100g 件 → 包 15~20g） | 我方规则 | O |
| 9 | 段取（洗螺杆料，kg） | 换料洗螺杆用料，按吨位固定：**<360t = 15，360t = 25，850t / 1300t = 50** | 我方规则 | R |
| 10 | 材料品种 + 牌号 | 从文件**读出品种和牌号**；单价查 `材料价格.md`，库里没有→询价附 POC | 客户文件 / 材料价格.md | 材料 → T |
| 11 | 加工时间（s） | **需专家评估**，默认按吨位：**160t = 30s，360t = 50s**，更大吨位待补 | 我方估算 | X |
| 12 | 机台费率（元/min） | 查 `机台费率.md`，**按吨位往高报** | 机台费率.md | Y |
| — | 运输费 | **总价 8%**，报总 | 我方规则 | AE |
| — | 包装费 | **总价 5%**，报总 | 我方规则 | AG |
| — | 模具费 | **必填**，询模具厂/用户，**不可估** | 用户提供 | AJ |

## 凑整规则（floor，务必遵守）

8% / 5% 是**下限（floor / 底线）**，不是可逼近的上限。凑整时**费用往上凑、让实际百分比 ≥ 目标**，**绝不能凑出 4.7 / 4.8 / 4.9% 这种低于线的数**。

- ❌ 总价 45，包装凑成 2.2 → 2.2/45 = 4.9% < 5%，不行
- ✅ 凑成 2.3 → 2.3/45 = 5.1% ≥ 5%，可以
- 原则：**宁可略高，不可略低。**

## 输出格式（★ 每次必产出一个新 MD 文件）

**硬性要求（required）**：**每次跑完 skill，必须生成一个新的 `.md` 文件**（如 `数据来源表_<项目/日期>.md`，存到当次询价文件夹或项目目录），用**表格**把今天定义的字段**全部列一遍**，并逐项标明**数据从哪儿来**。不是只在 terminal 打印——必须落盘成文件。

**每个零件一块，字段纵向列**，每项四要素：

| 字段 | 值（带单位） | 来源 | 含义 |
|---|---|---|---|

- **值**：带单位；英文加中文释义（文件名和 mm 除外）。
- **来源**：具体到文件 / 行 / 标题栏 / sheet。**能交叉验证时，两个数据源都要列出来**（例：重量 → Part List 标 77g ⇄ STP 86cc×0.9=77g，两源吻合）。
- **含义**：这个字段/值代表什么，让你一眼能核。
- 表内字段顺序与 Part 0「每零件字段表」一致，一个都不能少（含运输费、包装费、模具费）。

# Part 1 · Excel 字段清单（★ 默认由 skill 从客户文件夹自动挖掘，非人工录入）

> 模板：`注塑项目/金榕/产品报价内部格式.xlsx`（只读，勿改）。
>
> **默认原则**：下表所有字段，skill **都要自己从用户 dump 的客户资料文件夹里查出来 / 计算出来**，不等人工喂。
> **只有 3 类例外**不在文件夹里、需外部获取：
> 1. **模具费（AJ）** —— 必填，向模具厂/用户询价，不可估；

> 3. **我方规则/估算项** —— 料头(O)、段取(R)、加工时间(X)、利润率、运输/包装率等，用默认规则兜底，可选 override。

> 其余（车型、零件号、名称、模穴数、取数、总量、生命周期、制品重量、吨位…）**一律从客户图纸/Part List/BOM/模具方案里挖**。

# Part 2 · 公式固定列（程序直接写公式，不需人工输入）

| 列 | 字段名 | 公式（row 用实际行号替换） |
|---|---|---|
| M | 月批量 | `=ROUND(K{r}/L{r}/12*10000,-2)` |
| S | 使用重量 | `=(N{r}+O{r}*(1-P{r})/H{r})*(1+Q{r})+R{r}/M{r}` |
| U | 不良损耗 | `0.01`（固定值） |
| V | 部品材料费 | `=(S{r}*T{r}/1000)*(1+U{r})` |
| Z | 分钟机台费率 | `=Y{r}/60/0.9` |
| AA | 加工不良损耗 | `=U{r}` |
| AB | 加工费 | `=(Z{r}*X{r}/H{r})*(1+AA{r})` |
| AC | 材料管理费 | `=V{r}*0.03` |
| AD | 加工管理费 | `=AB{r}*0.08` |
| AI | 利润 | `=(V{r}+AB{r}+AC{r}+AD{r}+AE{r}+AG{r})*0.08` |
| AK | 模具分摊 | `=AJ{r}/总分摊量`（总分摊量 = 分摊年限 × 年量，项目级） |
| AL | 总计未税 | `=SUM(V{r}+AB{r}+AC{r}+AD{r}+AE{r}+AG{r}+AI{r}+AK{r})` |

# Part 3 · 运输/包装费的循环引用解法

AE（运输 **8%**）和 AG（包装 5%）如果直接写成 `=AL*8%`，会产生循环引用。
解析解推导（AE+AG = AL×13%，AI = (成本+AE+AG)×8%，回代得分母 = 1 − 13%×1.08 = **0.8596**）：

```
分母 = 0.8596        （= 1 − (8% + 5%) × (1 + 8%)）

AE = ((V + AB + AC + AD) * 1.08 + AK) / 0.8596 * 8%
AG = ((V + AB + AC + AD) * 1.08 + AK) / 0.8596 * 5%
```

> ⚠️ 原始 Excel 模板若仍编码 7% / 分母 0.8704，以本文件今日口径（8% / 0.8596）为准；
> 首次落到真实 Excel 前与专家确认一次。旧值：分母 0.8704 = 1 − (7%+5%)×1.08。
